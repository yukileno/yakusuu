# ポチポチ約数ハンター 〜まるつけマスター〜

小学校5年生向けの算数学習Webアプリ「ポチポチ約数ハンター」です。
教科書108ページのまとめ・練習問題【2】「次の数の約数に○をつけましょう」を忠実にゲーム化。
画面に並んだ1〜20等の数字ボタンをポチポチ選んで決定することで、「あまりなく割り切れる数（約数）」と「かけると元の数になるペア」の感覚を直感的に体得できます。

## 🎮 特徴とゲーミフィケーション
- **10インチタブレット最適化**: 16:9横向き1画面完結（スクロール不要）、48px以上の押しやすいボタン設計。
- **即時フィードバック**:
  - 正解時: パーフェクト演出＋「かけると元の数になるペア（例: 1×12, 2×6, 3×4）」の確認解説。
  - 不正解時: 「○はあまりが出るよ」「○も忘れないでね」の親切なヒント。
- **熱中要素**:
  - 連続正解コンボ（🔥 COMBO!）
  - フィーバータイム（⚡ 画面発光・得点2倍・時間ボーナス）
  - Web Audio APIによるピコピコ効果音（ボタン音、音階アップ、ファンファーレ）
  - 画面を彩るCanvas紙吹雪
  - 称号・ランク評価＆GAS全国ランキング連携
